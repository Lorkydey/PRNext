What the memory profile trades away

At 128 concurrent streaming clients, memory used 179 MiB versus balanced's 207 MiB, but delivered 362 rather than 726 responses/s. On concurrent SSR, memory used slightly more RAM than balanced. No profile wins on every metric.

Speed used about 5% more RAM than Next.js in fixed-rate SSR. In concurrent streaming, memory's first-byte p95 was 317.66 ms, compared with 122.79 ms for Next.js. The report includes these regressions.

Method and evidence

Apple M4 · 16 GiB · macOS ARM64 · Node.js 22.17.1 · Next.js 15.5.12. Same application sources; one PRNext build and binary. Uncached SSR and Suspense with one deterministic backend call delayed by 40 ms. Profiles run sequentially, reversing order every other repetition, with fresh servers and 64 warmup requests.

Each configuration proved 10,000 renders for 10,000 identical SSR requests. Three six-second repetitions per scenario. These instrumented local microbenchmarks are not endurance tests or cross-platform performance guarantees. No build or test suite ran during measurement. Flight and Actions are PRNext adaptations checked functionally but excluded from timed protocol comparisons.
